## Other points I noticed

1. **The clock has exceptions.** The abstract and Section 1.1 describe one clock, but Sections 4.2 and 4.6 explain that primary SPECK excludes model loading and some wrapper runs can overshoot. I would keep those exceptions visible and say that costs follow each campaign's stated clock rules.
2. **Complete does not mean exact.** Sections 4.3 and 4.5 separate sparse sampled tables, the sampled table with all 2^32 entries, and SIMON distributions calculated from a model. I would keep the word "sampled" beside the 4 GiB table. Calling it an exact cipher distribution or an optimal classical baseline would go too far.
3. **An attacker does not know the true position.** Sections 5.3.4-5.3.6 already separate analysis using true positions from forecasts made before the keys existed. I would also make this clear in Section 1.3: rank-quality estimates come from development keys, not knowledge of a new target's true position.
4. **The exact test needs a clear method.** Section 4.6 says exact McNemar. As I noted in audit 18, a conditional-binomial source or a short implementation explanation would help. I would also keep prediction intervals separate from confidence intervals.
5. **The later replication is a separate study.** Table 4 in this report has the 32-key full-table comparison and adjusted recovery p=0.063. [Timeline 12](../../timeline/12_replication_and_what_is_left.md) records a later 64-key replication on 27 October. Its 49/64 and 41/64 counts and p-value should not be inserted into the earlier table. The new cohort and protocol need their own description.
6. **The release link is still missing.** Appendix A and Section 4.7 promise a Zenodo deposit, but no DOI was supplied. I would add the actual repository link as code evidence and leave Zenodo marked as pending until the deposit exists.
7. **The declaration is not in this copy.** The structure guidance lists a Declaration of Originality before contributions. I could not find it in this draft. The editor should attach the official template; I have not created or signed a declaration for anyone.

## What I would fix first

I would start with the difference between schedule-free SAT assignments and a valid master key. Then I would qualify the cross-paper cost comparison and keep the clock and ground-truth limits clear. The reference fixes and blocked-page checks can follow.

Some round claims are already supported, and several limits are already stated correctly. I would keep those. This is a review of the sources and wording, not a new experiment or a claim that I independently reproduced the recovery campaigns.
