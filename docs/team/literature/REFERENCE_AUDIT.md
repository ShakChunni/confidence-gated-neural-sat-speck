# My reference checks

Notes updated: 27 October 2026 (Perth).

## What I checked

I compared the references in our report draft of 26 October with the publishers' records. It has 26 PDF pages. The reference list is not numbered, so I numbered the entries in the order they appear. The list is on printed pages 19-21, which are PDF pages 24-26. All section numbers below refer to that report version.

I used publisher pages rather than Google Scholar. Some pages opened normally; others were only available through the publisher's search listing or stopped at an access check. I have kept those cases separate. A page failing to load does not mean its DOI is wrong. I also checked the PDF pages visually, since extracted text can lose accents and formatting.

I have checked the first 13 references here. I will add the second half separately. Some checks still need a browser recheck or a citation export, as shown in the table.
